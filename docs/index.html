What the dataset tells us

The current dataset contains candidate bird identifications from recorded audio. The species ranking below shows which labels appeared most often in the retained model outputs.

A model detection is a lead for investigation — not a confirmed sighting. Listening and expert review are needed before drawing ecological conclusions.
